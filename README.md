# PRODIGY_WD_02 – Stopwatch Web Application

This project is a Stopwatch Web Application developed as part of the **Prodigy InfoTech Web Development Internship**.

The application provides an interactive stopwatch interface with a visually appealing background image for enhanced user experience.

## Features
- Start, Pause, and Reset stopwatch functionality
- Accurate time tracking (hours, minutes, seconds)
- Clean and responsive user interface
- Background image integrated using CSS
- Works smoothly across different screen sizes
  
## Technologies Used
- HTML5
- CSS3
- JavaScript
  
## Purpose
The purpose of this task was to strengthen understanding of JavaScript timing functions, DOM manipulation, and UI styling while building a functional and visually engaging web application.
